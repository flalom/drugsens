# Colorblind-safe categorical palette for drugsens plots

An 8-color categorical palette ordered for high contrast and
color-vision deficiency (CVD) safety across adjacent levels.

## Usage

``` r
drugsens_palette
```

## Format

A named character vector of 8 hex color codes: `blue`, `orange`, `aqua`,
`yellow`, `magenta`, `green`, `violet`, `red`.

## Examples

``` r
drugsens_palette
#>      blue    orange      aqua    yellow   magenta     green    violet       red 
#> "#2a78d6" "#eb6834" "#1baf7a" "#eda100" "#e87ba4" "#008300" "#4a3aa7" "#e34948" 
```
